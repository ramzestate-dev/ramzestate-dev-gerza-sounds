# gerza-sounds

Sound effects for video edits: impacts, whooshes, risers, weapons, nature, animals, ambience, UI,
music loops and more. All from OpenGameArt.org under CC0 (see `licenses/CREDITS.md`).

- Browse: [`CATALOG.csv`](CATALOG.csv)
- Download: release **v1** (one zip per category)
- Search and fetch: `./get-sound.sh удар меча` (needs `python3`, and `gh` or `curl`)

See [CLAUDE.md](CLAUDE.md) for details.
